FEATURES

一个词典该有的样子

①多语互查

英语 77 万词头带音标与词频；法语带音标、词性、阴阳性与完整屈折变化；日语带汉字表记、假名读音与变形还原（食べた → 食べる）；俄语收录 5000 高频词与常用变位。还能注册任意语言，没有词典包时由 AI 补录词条。输入中文也能反查外文词。

②离线词典 + AI 补全

英语词典随应用安装，法 / 日 / 俄与其他语言按需一键安装（更新不丢数据），查词不需要网络；没有词典的语言由 AI 现场补全并沉淀为词条。生词本、历史、设置都只存在你的设备上。

③真实语料例句

例句来自 Tatoeba 开源句库，配人工校对的中文翻译，不是机器拼凑的造句。

④AI 增强（可选）

自带 API Key 即可启用深度讲解、例句生成与释义补全；内置 29 家厂商预设（智谱 / DeepSeek / Kimi / MiniMax / OpenAI…）选厂商填 Key 即用。不配置则完全不影响使用，Key 只存在本机。

⑤干净清爽

无广告、无开屏、无账号体系、无统计埋点。纸墨排印，只留查词这一件事。

⑥开源可审计

应用源码与词典数据管道全部公开，数据源授权逐一署名，任何人都可以复核。
